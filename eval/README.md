# Evaluation set

`golden.jsonl` has 156 questions in one schema, from two sources:

| Source | Questions | What |
|---|---:|---|
| `shcd_quiz` | 30 | The official orientation-week (SHCD) multiple-choice quiz. Written by the university, so it is the least biased part of the set. |
| `synthetic` | 126 | Hand-written questions in the way students ask (short, informal, sometimes vague), covering all 18 documents |

|  | dev | test |
|---|---:|---:|
| must answer | 56 | 85 |
| must refuse | 6 | 9 |

shcd06 and shcd17 were relabelled from *answer* to *refuse* after the first dev run (the corpus has no answer
and the quiz's own answer is unknown). Every question has been checked by the author (`needs_review: false`).

## Rules

- **dev** is for building: prompt wording, top-k, the refusal threshold, the choice of embedder.
- **test** is run **once**, at the end, with every setting frozen. If test results lead to a change,
  the new number is a dev number and must be reported as such.
- The split is stratified by source × expected behaviour, with a fixed seed. It must not be changed
  after the first test run.

## Fields

| Field | Meaning |
|---|---|
| `id` | `shcdNN` (quiz) or `qNNN` (synthetic) |
| `split` | `dev` or `test` |
| `question`, `answer` | Reference answer in Vietnamese. For refusals it is the fixed refusal sentence |
| `options`, `gold_option` | Only for the multiple-choice quiz (`null` otherwise) |
| `expected_behavior` | `answer` or `refuse` |
| `type` | `so` (a number or limit), `dieu_kien` (a condition / consequence), `thu_tuc` (a procedure), `thong_tin` (facts, contacts), `tinh_toan` (needs a small calculation) |
| `multi_doc` | The answer needs more than one document |
| `citations` | `[{doc_id, loc, quote?, alternatives?}]`. `alternatives` lists other documents that state the same thing (either one is correct evidence). `loc` is human-readable (`Điều 25 khoản 2`, `III.2`, `mục 14`). `quote` is a short verbatim snippet of the evidence |
| `evidence_origin` | `internal` (portal documents), `web` (facts added from a web search), `none` |
| `withheld_answer` | For refusal tests built by removing a fact from the corpus: the real answer, which was withheld on purpose |
| `needs_review` | `true` until a human has checked the answer against the document |
| `note` | Why the question is tricky (near miss, partial answer, ambiguous wording) |

### Refusal questions
Most refusal questions are **near misses**: the topic is in the corpus but the asked fact is not.
- Example 1: library opening hours. The library's address is in the corpus, its hours are not.
- Example 2: the dormitory price. Only a scholarship discount is in the corpus.

These test whether the model refuses instead of answering from a nearby chunk.

## Gold chunks

`gold_chunks.json` is generated by `scripts/build_chunks.py`. It maps each question id to **one list of
chunk ids per citation**:
- a citation is covered when any chunk of its list is retrieved;
- a multi-document question is fully covered only when every list is.

A citation with a `quote` maps to exactly the chunks that contain the quote. A quote with a typo is
reported as unresolved, not guessed.

## Privacy

Answers paraphrase the documents and quotes are a few words long. The documents themselves are not
in the repository. The SHCD quiz screenshots contained a student's name and ID, so they are not stored.
